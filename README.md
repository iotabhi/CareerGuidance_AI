
# Career Guidance AI

AI-Based Career Recommendation and Personalized Learning Roadmap Using Semantic Networks.

## Features
- Semantic network-based career recommendations
- Student skill gap analysis
- Personalized learning roadmaps
- YouTube learning resource integration
- Interactive Streamlit interface

## Technologies
Python, Streamlit, NetworkX, Pandas, PyVis, YouTube Data API v3

## Installation

```bash
pip install -r requirements.txt
```

Create a `.env` file containing your own `YOUTUBE_API_KEY`.

## Run

```bash
streamlit run app.py
```
